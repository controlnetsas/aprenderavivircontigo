Cómo actualizar la lista cada semana

  1. En Excel, deja tu lista con dos columnas: nombre y whatsapp (la segunda es opcional).
  2. Archivo → Guardar como → elige el formato CSV (delimitado por comas).
  3. Nombra el archivo exactamente participantes-ruleta.csv.
  4. En hPanel → Administrador de archivos, entra a la carpeta raíz de tu sitio y sube ese archivo, reemplazando el anterior (acepta "Reemplazar").
  5. Vuelve a esta página y haz clic en "Recargar lista de esta semana" — no necesitas hacer nada en GitHub para esto.
